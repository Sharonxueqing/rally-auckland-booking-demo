# Rally Auckland tennis booking demo

A standalone browser demo for matching a player with a nearby tennis coach.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Demo notes

- Coach profiles, distances, ratings, prices, and remaining spots are sample data.
- Search uses the included Auckland suburb coordinates; it does not geocode arbitrary street addresses.
- Bookings update the page state and reset when the page reloads.
- This demo does not connect to coaches or confirm real availability.
